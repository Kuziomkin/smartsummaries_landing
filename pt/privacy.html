Política de Privacidade

Última atualização: 25 de janeiro de 2026

Esta Política de Privacidade explica como o Imagem para Texto: Smart Summaries (o “App” ou "Smart Summaries"), desenvolvido e operado por Dzianis Kuziomkin (“nós”, “nos” ou “nosso”), coleta, usa, divulga e protege informações quando você usa o App e serviços relacionados.

Ao usar o App, você concorda com o processamento de informações de acordo com esta Política de Privacidade. Se você não concordar com qualquer parte desta política, por favor, não use o App.

1. Visão Geral

Imagem para Texto: Smart Summaries é um aplicativo de interpretação de documentos que ajuda os usuários a entender textos de fotos extraindo, resumindo e traduzindo documentos. O App foi projetado para priorizar a privacidade do usuário e opera sem contas de usuário, servidores back-end proprietários ou bancos de dados centralizados.

2. Informações Que Não Coletamos

O Smart Summaries não coleta, armazena ou processa:

  • Identificadores pessoais (como nome, endereço de e-mail ou número de telefone).
  • Credenciais de conta ou informações de perfil.
  • Análises de uso, rastreamento comportamental ou dados de sessão.
  • Identificadores de dispositivo para publicidade (IDFA).
  • Dados de localização.
  • Informações de pagamento ou faturamento (processadas exclusivamente pela App Store).

Não operamos servidores back-end que armazenam dados do usuário.

3. Dados de Documentos e Processamento de IA

Quando você digitaliza ou envia um documento usando o App:

  • Armazenamento Local: A imagem do documento, o texto extraído e os resumos gerados são armazenados localmente no seu dispositivo. Você permanece no controle total desses dados e pode excluí-los a qualquer momento removendo o conteúdo do App ou desinstalando o App.
  • Processamento de IA: Para fornecer resumos e traduções, o App transmite o texto extraído ou os dados da imagem a um provedor de IA terceirizado, Google (provedor da API Gemini).
  • Sem Retenção por Nós: Não armazenamos seus documentos, textos ou resumos em nossos próprios servidores. A transmissão para o provedor de IA é transitória e realizada apenas para gerar a resposta.

4. Serviços de Terceiros

O Smart Summaries usa os seguintes serviços de terceiros para funcionar:

Google Gemini API (IA Generativa)

  • Finalidade: Analisar o texto do documento e gerar resumos/traduções.
  • Dados Compartilhados: Dados de imagem ou texto extraído de seus documentos.
  • Privacidade: Os dados enviados para a API são usados para gerar a resposta. Configuramos nossa implementação para minimizar a retenção de dados, mas o processamento de dados está sujeito aos termos de privacidade do Google. Não autorizamos terceiros a usar seus dados para treinar modelos de IA públicos.

Apple App Store

  • Finalidade: Processar pagamentos e gerenciar assinaturas.
  • Dados Compartilhados: As transações de pagamento são tratadas inteiramente pela Apple. Não temos acesso aos detalhes do seu cartão de crédito ou faturamento.

O Smart Summaries não usa ferramentas de análise de terceiros (como Google Analytics ou Mixpanel), SDKs de rastreamento ou redes de publicidade.

5. Segurança de Dados

Como o Smart Summaries não mantém servidores externos para dados do usuário, seus documentos permanecem no seu dispositivo. Quando os dados são transmitidos ao provedor de IA para processamento, são enviados via criptografia segura (HTTPS/TLS).

No entanto, nenhum método de transmissão pela internet ou armazenamento eletrônico é 100% seguro. Embora nos esforcemos para usar meios comercialmente aceitáveis para proteger seus dados, não podemos garantir sua segurança absoluta.

6. Privacidade das Crianças

O Smart Summaries não se destina ao uso por crianças menores de 13 anos. Não coletamos intencionalmente informações pessoais de crianças.

7. Seus Direitos

Como o Smart Summaries não coleta, sincroniza ou armazena dados pessoais em nossos servidores, não mantemos dados pessoais para acessar, modificar ou excluir. Você tem controle total sobre seus dados; excluir um documento dentro do App ou desinstalar o App remove permanentemente os dados do seu dispositivo.

8. Alterações nesta Política de Privacidade

Podemos atualizar esta Política de Privacidade para refletir alterações no App ou requisitos legais. Quaisquer atualizações serão publicadas nesta página com uma data de “Última atualização” atualizada. O uso contínuo do App após as alterações constitui aceitação da política atualizada.
