Política de Privacidad

Última actualización: 25 de enero de 2026

Esta Política de Privacidad explica cómo Image to Text: Smart Summaries (la “Aplicación” o "Smart Summaries"), desarrollada y operada por Dzianis Kuziomkin (“nosotros”, “nos” o “nuestro”), recopila, utiliza, divulga y protege la información cuando utilizas la Aplicación y los servicios relacionados.

Al usar la Aplicación, aceptas el procesamiento de información de acuerdo con esta Política de Privacidad. Si no estás de acuerdo con alguna parte de esta política, por favor no uses la Aplicación.

1. Resumen

Image to Text: Smart Summaries es una aplicación de interpretación de documentos que ayuda a los usuarios a entender texto a partir de fotos extrayendo, resumiendo y traduciendo documentos. La Aplicación está diseñada para priorizar la privacidad del usuario y opera sin cuentas de usuario, servidores backend propietarios o bases de datos centralizadas.

2. Información que No Recopilamos

Smart Summaries no recopila, almacena ni procesa:

  • Identificadores personales (como nombre, dirección de correo electrónico o número de teléfono).
  • Credenciales de cuenta o información de perfil.
  • Análisis de uso, seguimiento de comportamiento o datos de sesión.
  • Identificadores de dispositivo para publicidad (IDFA).
  • Datos de ubicación.
  • Información de pago o facturación (procesada únicamente por la App Store).

No operamos servidores backend que almacenen datos de usuarios.

3. Datos de Documentos y Procesamiento de IA

Cuando escaneas o subes un documento usando la Aplicación:

  • Almacenamiento Local: La imagen del documento, el texto extraído y los resúmenes generados se almacenan localmente en tu dispositivo. Tú permaneces en control total de estos datos y puedes eliminarlos en cualquier momento eliminando contenido dentro de la Aplicación o desinstalando la Aplicación.
  • Procesamiento de IA: Para proporcionar resúmenes y traducciones, la Aplicación transmite el texto extraído o los datos de la imagen a un proveedor de IA de terceros, Google (proveedor de la API Gemini).
  • Sin Retención por Nuestra Parte: No almacenamos tus documentos, texto o resúmenes en nuestros propios servidores. La transmisión al proveedor de IA es transitoria y se realiza únicamente para generar la respuesta.

4. Servicios de Terceros

Smart Summaries utiliza los siguientes servicios de terceros para funcionar:

Google Gemini API (IA Generativa)

  • Propósito: Analizar texto de documentos y generar resúmenes/traducciones.
  • Datos Compartidos: Datos de imagen o texto extraído de tus documentos.
  • Privacidad: Los datos enviados a la API se utilizan para generar la respuesta. Hemos configurado nuestra implementación para minimizar la retención de datos, pero el procesamiento de datos está sujeto a los términos de privacidad de Google. No autorizamos a terceros a utilizar tus datos para entrenar modelos de IA públicos.

Apple App Store

  • Propósito: Procesar pagos y gestionar suscripciones.
  • Datos Compartidos: Las transacciones de pago son manejadas completamente por Apple. Nosotros no tenemos acceso a tu tarjeta de crédito o detalles de facturación.

Smart Summaries no utiliza herramientas de análisis de terceros (como Google Analytics o Mixpanel), SDKs de seguimiento o redes publicitarias.

5. Seguridad de Datos

Debido a que Smart Summaries no mantiene servidores externos para datos de usuarios, tus documentos permanecen en tu dispositivo. Cuando los datos se transmiten al proveedor de IA para su procesamiento, se envían mediante cifrado seguro (HTTPS/TLS).

Sin embargo, ningún método de transmisión a través de Internet o almacenamiento electrónico es 100% seguro. Aunque nos esforzamos por utilizar medios comercialmente aceptables para proteger tus datos, no podemos garantizar su seguridad absoluta.

6. Privacidad de los Niños

Smart Summaries no está destinado para su uso por niños menores de 13 años. No recopilamos conscientemente información personal de niños.

7. Tus Derechos

Dado que Smart Summaries no recopila, sincroniza ni almacena datos personales en nuestros servidores, no tenemos ningún dato personal para acceder, modificar o eliminar. Tienes control total sobre tus datos; eliminar un documento dentro de la Aplicación o desinstalar la Aplicación elimina permanentemente los datos de tu dispositivo.

8. Cambios a esta Política de Privacidad

Podemos actualizar esta Política de Privacidad para reflejar cambios en la Aplicación o requisitos legales. Cualquier actualización será publicada en esta página con una fecha de “Última actualización” actualizada. El uso continuo de la Aplicación después de los cambios constituye la aceptación de la política actualizada.
